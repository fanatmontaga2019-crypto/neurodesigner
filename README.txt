Публикация в существующем проекте Vercel:
1. Сохраните резервную копию сайта.
2. Замените файлы проекта содержимым этого архива на том же уровне,
   где находится прежний index.html. Не изменяйте без необходимости
   существующие настройки Vercel.
3. Если Vercel связан с GitHub, сохраните изменения в репозитории
   (commit/push) и дождитесь завершения нового развёртывания.
4. Проверьте сайт и при необходимости обновите страницу без кэша.
Старые assets/neon и assets/neon.css больше не нужны, их можно удалить.

отправляет из неё самостоятельно. Серверной отправки нет.
